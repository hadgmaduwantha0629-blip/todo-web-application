# Todo Web Application

A full-stack Todo Web Application built using Laravel and Next.js.

## Tech Stack

### Backend

- Laravel
- PostgreSQL
- Sanctum Authentication

### Frontend

- Next.js
- React
- Axios
- Tailwind CSS

## Features

- User Registration
- User Login
- Logout
- Create Todo
- Update Todo
- Delete Todo
- Search Todos
- Filter Todos
- Mark Complete/Pending

## Project Structure

```
Todo-Web-Application
├── Back-End
└── front-end
```
